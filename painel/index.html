Grid no site

Como o grid se forma

Entra no grid de serviços da página /inicio/ todo produto no ar, marcado para aparecer no site, com título e link. A ordem do grid é a ordem desta lista (setas à direita de cada linha). O site lê o catálogo a cada visita, com até um minuto de atraso.

Trilhos e degraus

Trilho é para quem o produto é: cliente final, corretores, construtoras e incorporadoras, escritórios. Degrau é a posição no caminho até o contrato: entrada (grátis), pago leve ou contrato (o serviço principal). Material só para parceiros fica fora do grid.

Nada se apaga

Produto que saiu dos planos vai para Arquivados. Cada gravação guarda o catálogo anterior (as 20 últimas versões ficam no servidor).
